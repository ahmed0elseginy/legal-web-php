Web Development Complete Report

Project: MIZAN Legal Services Platform

P1: Identify Dynamic Web Pages Terminologies

Dynamic web pages are pages that display different content for different users while retaining the same layout and design. Key terminologies include:

  • DOM (Document Object Model): A programming interface for HTML and XML documents. It represents the page so that programs (like JavaScript) can change the document structure, style, and content.
  • AJAX (Asynchronous JavaScript and XML): A technique using the XMLHttpRequest object to communicate with servers. It can send and receive information in various formats, including JSON, XML, HTML, and text files.
  • Client-Side Scripting: Code that runs in the user's web browser (e.g., JavaScript).
  • Server-Side Scripting: Code that runs on the web server (e.g., PHP, Node.js) to generate customized responses for each user.
  • Web Server: Hardware or software that responds to client requests over the World Wide Web.
  • Database: An organized collection of data, generally stored and accessed electronically from a computer system (e.g., MySQL used in MIZAN).

P2: Different Protocols and Backend Technologies

Protocols

  • HTTP (Hypertext Transfer Protocol): The foundation of data communication for the World Wide Web, used for loading web pages via hypertext links.
  • HTTPS (HTTP Secure): An extension of HTTP. It is used for secure communication over a computer network, widely used on the Internet.
  • FTP (File Transfer Protocol): A standard network protocol used for the transfer of computer files between a client and server.
  • WebSocket: A computer communications protocol, providing full-duplex communication channels over a single TCP connection.

Backend Technologies

  • PHP: A widely-used open source general-purpose scripting language that is especially suited for web development and can be embedded into HTML. (Used in this project)
  • Node.js: An open-source, cross-platform, back-end JavaScript runtime environment that executes JavaScript code outside a web browser.
  • Python (Django/Flask): High-level programming language used widely for robust and scalable backend systems.
  • Ruby on Rails: A server-side web application framework written in Ruby.

M1: Javascript Techniques & Libraries to Enhance the Web

Enhancing web connectivity and user experience relies heavily on modern JS techniques:

  • Fetch API / Axios: Used over older XMLHttpRequest for making HTTP requests to servers (AJAX). Fetch provides a better, more powerful, and flexible feature set.
  • React / Vue.js: Frontend libraries/frameworks that allow developers to build encapsulated components that manage their own state, then compose them to make complex UIs efficiently using Virtual DOM calculations.
  • jQuery: A fast, small, and feature-rich JavaScript library. While less common in new projects due to modern Vanilla JS features, it makes things like HTML document traversal and manipulation, event handling, and animation much simpler across a multitude of browsers.
  • Asynchronous Programming (Async/Await): Helps write asynchronous, promise-based behavior in a cleaner style, avoiding "callback hell" and making code easily maintained.

M2 & M3: Cookies & Session for Web Connectivity

Cookies vs. Sessions: HTTP is a stateless protocol, meaning each request is completely independent. Cookies and Sessions are used to persist data across multiple requests.
Feature Cookies Sessions
Storage Location Stored on the client's browser as text files. Stored on the web server.
Security Less secure as data can be read/modified by the client. More secure as data is hidden on the server (only a session ID is stored on client).
Capacity Max 4KB per cookie. Virtually unlimited (depends on server setup/memory).
Lifespan Can persist even after the browser is closed (until expiration). Typically ends when the user closes the browser.

Application in MIZAN Project: In the MIZAN system, Session (`$_SESSION`) is used to maintain the lawyer or client's logged-in status securely. A Cookie (`setcookie()`) has been implemented for the "Remember Me" feature, which keeps the user authenticated even if they close their browser and return later.

D1: Differences Between Server-Side and Client-Side

The distinction between Client-Side and Server-Side is fundamental to Web Architecture:

  • Client-Side (Frontend): Everything that the user visually sees and interacts with in their web browser. Technologies include HTML, CSS, and JavaScript. Processing happens on the user's local computer. It is responsible for UI presentation, form validation (immediate feedback), and dynamic visuals.
  • Server-Side (Backend): The hidden infrastructure that powers the website. It consists of the server, a database, and server-side applications (PHP, Node API). Processing happens on a remote web server. It is responsible for business logic, database queries, authentication/authorization, and security.

Integration (D2): Modern dynamic websites bridge these two using AJAX/APIs. For example, in the MIZAN registration page, Client-Side JavaScript uses `fetch()` to send data to a Server-Side PHP script (`check_email.php`), which queries the database and returns a Server-Side response to be dynamically rendered on the Client-Side without reloading the page.
